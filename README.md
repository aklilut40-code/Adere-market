Adere Market

A small demo storefront for a local produce market in Mekelle — browse products by category and add items to a basket. Pure HTML/CSS/JS, no build step, so it deploys straight to GitHub Pages.

## Features
- Category filtering (vegetables, grains, spices, dairy)
- Add-to-basket with live count and running total
- Responsive layout, works down to mobile

## Deploy on GitHub Pages (from your phone)

1. On GitHub, tap **+** → **New repository**. Name it something like `adere-market`. Make it **Public**. Create it.
2. Open the new repo → **Add file** → **Upload files**.
3. Upload `index.html` (and this `README.md` if you like).
4. Commit the changes.
5. Go to the repo's **Settings** → **Pages** (scroll down the settings menu on mobile if needed).
6. Under **Build and deployment** → **Source**, choose **Deploy from a branch**.
7. Under **Branch**, choose `main` and folder `/ (root)`, then **Save**.
8. Wait 1–2 minutes, then refresh the Pages settings page — your live link will appear at the top, something like:
   `https://your-username.github.io/adere-market/`

That link is what you paste into the "Live Demo" line above and into your portfolio site.
